# Household Toolbox

Household Toolbox is a digital toolbox for household management.

## Documentation

| File | What it is for |
|------|----------------|
| [`UX_DESIGN_STANDARD.md`](./UX_DESIGN_STANDARD.md) | How the interface should **look and behave**. Authoritative for colors, theme, typography, buttons, forms, lists, modals, attachments UX, print/export, accessibility, per-tool UX exceptions, and stable audit rule IDs. |
| [`UX_AUDIT_CHECKLIST.md`](./UX_AUDIT_CHECKLIST.md) | QA worksheet for auditing one tool against those rule IDs. |
| [`system_design.md`](./system_design.md) | Technical architecture, database standards, security, Supabase conventions, project setup, and other engineering standards. |

If an older UI snippet in `system_design.md` disagrees with `UX_DESIGN_STANDARD.md`, the UX document wins.

Use `system_design.md` for:
- Product and technical overview
- Setup essentials and environment configuration
- Database standards and migration guidance
- Operational notes and implementation standards
